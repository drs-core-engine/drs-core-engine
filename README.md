### 👥 About this account

This is a **team account**, not a single person. Commits, pull requests and issues from `drs-core-engine` are made by the DevRight Studios core engineering group and its tooling, on behalf of the studio.

### 🧩 What we work on

| Area | Focus |
|---|---|
| 🧠 **Core runtime** | Logging and crash handling, memory, jobs, the virtual file system, console and config |
| 🌌 **Simulation** | ECS, double-precision physics, large-world spatial frames |
| 🎨 **Rendering** | DirectX 12 device and render pipeline |
| 🏭 **Pipeline** | Asset cooking, build tooling, test and CI gates |

### 📐 How we work

- 📚 **Docs first.** Design docs are the source of truth, and code follows them.
- ✅ **Every fix is tested.** Each bug gets an issue and a regression test that fails on the old code.
- 🚦 **Gated merges.** Sanitizer builds, warnings as errors, and a reviewed sign-off before anything lands.
